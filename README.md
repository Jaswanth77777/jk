# Taskflow — Task Tracker

A responsive browser-based task tracker published as a GitHub Pages site.

## Live demo
https://jaswanth77777.github.io/jk/

## Features
- Create, edit, complete and delete tasks
- Search task titles and descriptions
- Filter by status and view all / today / upcoming / completed
- Summary cards and due dates
- Responsive layout and dark theme toggle
- Saves tasks in this browser using localStorage

## Hosting note
The uploaded project uses PHP and MySQL. GitHub Pages cannot execute PHP or connect to MySQL. The root website is therefore a static browser-based version; tasks are saved only in each visitor's browser and there are no secure accounts or shared multi-user data. The original PHP/MySQL app needs a PHP host with MySQL/MariaDB to run as designed.

## Local preview
Open index.html in a modern browser or serve this folder with a static web server.
